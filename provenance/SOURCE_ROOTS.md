# Procedencia sin rutas privadas

WORKSPACE: repositorio de trabajo; EXPERIMENT_ROOT: directorio separado de resultados A0/A1/A2; DOWNLOADS: carpeta local donde se recuperaron lock y cierre. Las rutas relativas originales se conservan con estos alias. La tabla con rutas absolutas se guarda fuera del paquete en outputs/code_release_preparation/local_source_inventory.json y no forma parte del ZIP.

Los archivos originales copiados son byte-idénticos. Los archivos depurados o documentales se marcan RECONSTRUIDO, con hash del original y descripción de cambios. Los originales privados no se redistribuyen. No se afirma que RECONSTRUIDO sea código histórico.
